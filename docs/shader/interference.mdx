## Setup notes

Requires React and Tailwind CSS 4. The installation includes all local dependencies. No API keys or external assets are needed.

Give the parent an explicit height. Use `frequency` to change the ring density and `paused` to freeze motion. The shader respects reduced-motion preferences and falls back to a gradient without WebGL.
