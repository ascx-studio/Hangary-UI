## Overview

Shared exports for the portfolio blog building blocks.

## Usage

Use the exports from the installed entry file:

```text
@components/lazy-ui/blocks/blog/index.ts
```

## Setup notes

Imported from the portfolio project. Customize personal copy, links, social profiles, booking URLs, and data before use. Requires React 19, Next.js 16, Tailwind CSS 4, and shadcn theme variables. Files install under your components alias in lazy-ui/, with their relative imports preserved. Import the installed lazy-ui/styles/portfolio.css in your global stylesheet. For Base UI animation utilities, also import shadcn/tailwind.css. Mount react-hot-toast Toaster once in your application. Configure NOTION_SECRET (or NOTION_API_KEY), NOTION_DATA_SOURCE_ID and/or NOTION_BLOG_DATA_SOURCE_ID. Keep these helpers server-side; the blog cache functions require cacheComponents: true. Configure next/image remotePatterns for the external images you use.
