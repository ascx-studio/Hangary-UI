## Overview

A responsive Northstar sign-in block with accessible fields and a safe demo submit state.

## Installation

```bash
npx shadcn@latest add https://ui.rajeevpuri.com.np/r/split-sign-in.json
```

## Usage

Import and render `SplitSignIn`:

```tsx
import { SplitSignIn } from "@/components/lazy-ui/blocks/split-sign-in"

export default function Example() {
  return <SplitSignIn />
}
```

## Setup notes

Requires React 19.3 or later and Tailwind CSS 4. Import the shared `morph.css` stylesheet after Tailwind for the enter and exit animation classes. This is UI only; connect a server-side authentication provider for real accounts.
