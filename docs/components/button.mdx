## Overview

Displays a button or a component that looks like a button with link support.

## Usage

```tsx
<Button variant="primary">Save changes</Button>
<Button variant="ghost">Cancel</Button>
```

Use the exports from the installed entry file:

```text
registry/nova-blue/ui/button.tsx
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application. The source files below show its exports and supported props.
