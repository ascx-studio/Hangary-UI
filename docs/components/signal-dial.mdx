## Setup notes

Requires React and Tailwind CSS 4. The installation includes all local dependencies. No API keys or external assets are needed.

Use `defaultValue` for an uncontrolled dial, or `value` and `onValueChange` inside a client component for controlled tuning. Values range from 0 to 100; `label` names the accessible control.
