## Overview

Reusable SVG illustrations for service cards.

## Usage

Use the exports from the installed entry file:

```text
@components/lazy-ui/components/illustration/service-illustrations.tsx
```

## Setup notes

Imported from the portfolio project. Customize personal copy, links, social profiles, booking URLs, and data before use. Requires React 19, Next.js 16, Tailwind CSS 4, and shadcn theme variables. Files install under your components alias in lazy-ui/, with their relative imports preserved. Import the installed lazy-ui/styles/portfolio.css in your global stylesheet. For Base UI animation utilities, also import shadcn/tailwind.css.
