## Overview

Displays a card with border and shadow styling matching the Lazy UI theme.

## Usage

```tsx
<Card className="p-6">
  <h2>Project overview</h2>
  <p>Keep related content together.</p>
</Card>
```

Use the exports from the installed entry file:

```text
registry/nova-blue/ui/card.tsx
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application. The source files below show its exports and supported props.
