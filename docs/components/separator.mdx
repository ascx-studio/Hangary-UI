## Overview

Horizontal and vertical dividers with accessible semantics.

## Usage

```tsx
<Separator />
<div className="flex h-8 gap-4">
  Profile <Separator orientation="vertical" /> Settings
</div>
```

Use the exports from the installed entry file:

```text
registry/nova-blue/ui/separator.tsx
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application. The source files below show its exports and supported props.
