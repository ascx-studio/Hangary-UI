## Overview

Messages with a title, description, and destructive variant.

## Usage

```tsx
<Alert>
  <AlertTitle>Changes saved</AlertTitle>
  <AlertDescription>Your settings are up to date.</AlertDescription>
</Alert>
```

Use the exports from the installed entry file:

```text
registry/nova-blue/ui/alert.tsx
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application. The source files below show its exports and supported props.
