## Overview

An animated typography component with configurable text, motion, tempo, and spacing.

## Installation

```bash
npx shadcn@latest add https://ui.rajeevpuri.com.np/r/kinetic-type-lab.json
```

## Usage

Import the component and render it:

```tsx
import { KineticTypeLab } from "@/components/lazy-ui/components/kinetic-type-lab"

export default function Example() {
  return <KineticTypeLab text="MAKE WAVES" amplitude={24} speed={1.8} tracking={-0.07} playing />
}
```

## Setup notes

The registry entry includes its CSS file. Adjust `text`, `amplitude`, `speed`, `tracking`, and `playing` in the item details panel to preview each prop. Motion pauses automatically when the visitor prefers reduced motion.
