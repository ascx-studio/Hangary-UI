## Overview

Editable technical skills with their display icons.

## Usage

Use the exports from the installed entry file:

```text
@components/lazy-ui/lib/skills-data.tsx
```

## Setup notes

Imported from the portfolio project. Customize personal copy, links, social profiles, booking URLs, and data before use. Requires React 19, Next.js 16, Tailwind CSS 4, and shadcn theme variables. Files install under your components alias in lazy-ui/, with their relative imports preserved.
