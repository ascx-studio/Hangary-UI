## Overview

Reusable project-placeholder.ts from the Nova Blue collection.

## Installation

```bash
npx shadcn@latest add https://ui.rajeevpuri.com.np/r/nova-blue-lib-project-placeholder.json
```

## Usage

Use the exports from the installed entry file:

```text
@/components/lazy-ui/lib/project-placeholder.ts
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application.
