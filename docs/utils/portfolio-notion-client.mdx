## Overview

Server-side Notion client configuration.

## Usage

Use the exports from the installed entry file:

```text
@components/lazy-ui/lib/notion/client.ts
```

## Setup notes

Imported from the portfolio project. Customize personal copy, links, social profiles, booking URLs, and data before use. Requires React 19, Next.js 16, Tailwind CSS 4, and shadcn theme variables. Files install under your components alias in lazy-ui/, with their relative imports preserved. Configure NOTION_SECRET (or NOTION_API_KEY), NOTION_DATA_SOURCE_ID and/or NOTION_BLOG_DATA_SOURCE_ID. Keep these helpers server-side; the blog cache functions require cacheComponents: true.
