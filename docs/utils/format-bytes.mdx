## Overview

Format byte counts using binary units such as KiB and MiB.

## Installation

```bash
npx shadcn@latest add https://ui.rajeevpuri.com.np/r/format-bytes.json
```

## Usage

Use the exports from the installed entry file:

```text
@/components/lazy-ui/lib/format-bytes.ts
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application.
