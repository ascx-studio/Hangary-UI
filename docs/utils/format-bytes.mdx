## Overview

Format byte counts using binary units such as KiB and MiB.

## Usage

```ts
import { formatBytes } from "@/lib/format-bytes"

formatBytes(1536) // "1.5 KiB"
formatBytes(1048576) // "1 MiB"
```

Use the exports from the installed entry file:

```text
registry/nova-blue/lib/format-bytes.ts
```

## Setup notes

Uses binary units (1024 bytes per KiB). Precision defaults to one decimal place; pass an integer from 0 to 6. Trailing zeroes are removed. Negative or non-finite byte counts and invalid precision throw a RangeError.
