## Overview

Keep a finite number within an inclusive range.

## Usage

```ts
import { clamp } from "@/lib/clamp"

clamp(120, 0, 100) // 100
clamp(-10, 0, 100) // 0
```

Use the exports from the installed entry file:

```text
registry/nova-blue/lib/clamp.ts
```

## Setup notes

Bounds are inclusive. Non-finite inputs or a minimum greater than the maximum throw a RangeError.

Install the entry and its dependencies, then adapt the content and styles to your application. The source files below show its exports and supported props.
