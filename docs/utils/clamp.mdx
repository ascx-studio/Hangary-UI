## Overview

Keep a finite number within an inclusive range.

## Installation

```bash
npx shadcn@latest add https://ui.rajeevpuri.com.np/r/clamp.json
```

## Usage

Use the exports from the installed entry file:

```text
@/components/lazy-ui/lib/clamp.ts
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application.
