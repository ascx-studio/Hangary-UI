## Overview

Merge conditional class names and resolve Tailwind conflicts.

## Usage

```ts
import { cn } from "@/lib/cn"

cn("rounded p-4", isActive && "bg-primary")
```

Use the exports from the installed entry file:

```text
registry/nova-blue/lib/cn.ts
```

## Setup notes

Accepts conditional classes and resolves conflicting Tailwind utilities. Later conflicting classes take precedence.

Install the entry and its dependencies, then adapt the content and styles to your application. The source files below show its exports and supported props.
