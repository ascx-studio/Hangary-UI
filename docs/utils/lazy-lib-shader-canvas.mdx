## Overview

Reusable shader-canvas.tsx from the Lazy UI collection.

## Installation

```bash
npx shadcn@latest add https://ui.rajeevpuri.com.np/r/lazy-lib-shader-canvas.json
```

## Usage

Use the exports from the installed entry file:

```text
@/components/lazy-ui/lib/shader-canvas.tsx
```

## Setup notes

Install the entry and its dependencies, then adapt the content and styles to your application.
