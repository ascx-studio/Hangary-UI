## Setup

Add the installed stylesheet after Tailwind in your global stylesheet:

```css
@import "tailwindcss";
@import "@/components/lazy-ui/styles/morph.css";
```

The numbered `auth`, `navbar`, and `footer` blocks include this stylesheet as a registry dependency. No animation package is required.
