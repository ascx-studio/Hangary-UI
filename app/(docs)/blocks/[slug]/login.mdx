# Login

A card login form with provider buttons, password visibility, and loading and error states.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/login.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/login.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/login.json",
}} />

## Usage

```tsx
"use client";

import type { ComponentProps } from "react";
import { Login } from "@/components/lazy-ui/blocks/login";

// Pass your application's authentication handlers to this form.
export function SignIn(props: Pick<ComponentProps<typeof Login>,
  "onSubmit" | "onProviderLogin" | "loading" | "error">) {
  return <Login brand="Acme" {...props} />;
}
```

## Other styles

Each login style is a separate block. Login uses a Card, LoginSplit adds a testimonial panel, and LoginMinimal removes the frame. All three accept the same authentication callbacks and loading and error props.

- [Login Split](/blocks/login-split)
- [Login Minimal](/blocks/login-minimal)

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`, with no rounded classes. The registry bundles the existing components used by the block.

Connect `onSubmit` and `onProviderLogin` to your authentication implementation. These blocks provide the interface; the previews do not submit credentials or authenticate. Handle request state with `loading` and `error`, and customize the reset-password and registration destinations.
