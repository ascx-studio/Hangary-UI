# Pricing Compact

Pricing plans presented as compact horizontal rows.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/pricing-compact.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/pricing-compact.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/pricing-compact.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/pricing-compact.json",
}} />

## Usage

```tsx
import { PricingCompact } from "@/components/hangry-ui/blocks/pricing-compact";

<PricingCompact
  defaultBilling="yearly"
  plans={[
    {
      name: "Pro",
      description: "Everything you need to build.",
      monthlyPrice: 19,
      yearlyPrice: 15,
      features: ["Unlimited projects", "Priority support"],
      href: "/signup?plan=pro",
      label: "Choose Pro",
      featured: true,
    },
  ]}
/>
```
