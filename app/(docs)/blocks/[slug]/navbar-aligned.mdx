# Left-Aligned Navbar

A navbar with navigation links beside the brand.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/navbar-aligned.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/navbar-aligned.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/navbar-aligned.json",
}} />

## Usage

```tsx
import { NavbarAligned } from "@/components/lazy-ui/blocks/navbar-aligned";

<NavbarAligned
  brand="Acme"
  badge=""
  activeHref="/products"
  links={[
    { label: "Products", href: "/products" },
    { label: "About", href: "/about" },
  ]}
  githubHref="https://github.com/acme"
  supportHref="/support"
/>
```

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`, with no rounded classes. The registry bundles the components this block uses. Customize the links and content for your application.
