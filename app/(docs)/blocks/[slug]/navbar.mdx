# Centered Navbar

A navbar with centered desktop links, support and GitHub actions, and a mobile menu.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/navbar.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/navbar.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/navbar.json",
}} />

## Usage

```tsx
import { Navbar } from "@/components/lazy-ui/blocks/navbar";

<Navbar
  brand="Acme"
  badge=""
  activeHref="/products"
  links={[
    { label: "Products", href: "/products" },
    { label: "About", href: "/about" },
  ]}
  githubHref="https://github.com/acme"
  supportHref="/support"
/>
```

## Other styles

Each navbar style is a separate block. The centered Navbar keeps its brand on the left and actions on the right. NavbarAligned places links beside the brand; NavbarFloating adds an inset surface. All styles share the mobile menu behavior.

- [Left-Aligned Navbar](/blocks/navbar-aligned)
- [Floating Navbar](/blocks/navbar-floating)

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`, with no rounded classes. The registry bundles the components this block uses. Customize the links and content for your application.
