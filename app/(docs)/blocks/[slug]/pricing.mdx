## How to use

```tsx
import { Pricing } from "@/components/hangry-ui/blocks/pricing";

<Pricing
  defaultBilling="yearly"
  plans={[
    {
      name: "Pro",
      description: "Everything you need to build.",
      monthlyPrice: 19,
      yearlyPrice: 15,
      features: ["Unlimited projects", "Priority support"],
      href: "/signup?plan=pro",
      label: "Choose Pro",
      featured: true,
    },
  ]}
/>;
```
