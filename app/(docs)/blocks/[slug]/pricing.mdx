# Pricing

A pricing card grid with featured plans and monthly or yearly billing.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/pricing.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/pricing.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/pricing.json",
}} />

## Usage

```tsx
import { Pricing } from "@/components/lazy-ui/blocks/pricing";

<Pricing
  defaultBilling="yearly"
  plans={[
    {
      name: "Pro",
      description: "Everything you need to build.",
      monthlyPrice: 19,
      yearlyPrice: 15,
      features: ["Unlimited projects", "Priority support"],
      href: "/signup?plan=pro",
      label: "Choose Pro",
      featured: true,
    },
  ]}
/>
```

## Other styles

Each pricing style is a separate block. Pricing uses cards, PricingCompact uses horizontal rows, and PricingComparison uses a Table. All three support monthly and yearly billing.

- [Pricing Compact](/blocks/pricing-compact)
- [Pricing Comparison](/blocks/pricing-comparison)

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`, with no rounded classes. The registry bundles the existing components used by the block.

Customize the plan data and checkout links. The default plan names, prices, and benefits are sample content; this block does not create subscriptions or charge customers.
