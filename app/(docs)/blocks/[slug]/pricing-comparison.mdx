# Pricing Comparison

A pricing comparison table with billing controls.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.rajeevpuri.com.np/r/pricing-comparison.json",
  npm: "npx shadcn@latest add https://ui.rajeevpuri.com.np/r/pricing-comparison.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.rajeevpuri.com.np/r/pricing-comparison.json",
}} />

## Usage

```tsx
import { PricingComparison } from "@/components/lazy-ui/blocks/pricing-comparison";

<PricingComparison
  defaultBilling="yearly"
  plans={[
    {
      name: "Pro",
      description: "Everything you need to build.",
      monthlyPrice: 19,
      yearlyPrice: 15,
      features: ["Unlimited projects", "Priority support"],
      href: "/signup?plan=pro",
      label: "Choose Pro",
      featured: true,
    },
  ]}
/>
```

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`, with no rounded classes. The registry bundles the existing components used by the block.

Customize the plan data and checkout links. The default plan names, prices, and benefits are sample content; this block does not create subscriptions or charge customers.
