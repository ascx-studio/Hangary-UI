# Pricing Comparison

A pricing comparison table with billing controls.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/pricing-comparison.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/pricing-comparison.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/pricing-comparison.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/pricing-comparison.json",
}} />

## Usage

```tsx
import { PricingComparison } from "@/components/hangry-ui/blocks/pricing-comparison";

<PricingComparison
  defaultBilling="yearly"
  plans={[
    {
      name: "Pro",
      description: "Everything you need to build.",
      monthlyPrice: 19,
      yearlyPrice: 15,
      features: ["Unlimited projects", "Priority support"],
      href: "/signup?plan=pro",
      label: "Choose Pro",
      featured: true,
    },
  ]}
/>
```
