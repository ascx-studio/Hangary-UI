# Column Footer

A footer with grouped link columns, brand details, and an optional card callout.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/footer.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/footer.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/footer.json",
}} />

## Usage

```tsx
import { Footer } from "@/components/lazy-ui/blocks/footer";

<Footer
  brand="Acme"
  description="Tools for your next idea."
  copyright="© 2026 Acme"
  githubHref="https://github.com/acme"
  groups={[
    { title: "Company", links: [
      { label: "About", href: "/about" },
      { label: "Contact", href: "/contact" },
    ] },
  ]}
  callout={{
    title: "Build something new",
    description: "Explore the component collection.",
    label: "Get started",
    href: "/components",
  }}
/>
```

## Other styles

Each footer style is a separate block. Footer uses link columns, FooterMinimal uses inline navigation, and FooterStacked centers its content. Provide callout to add a Card above any style.

- [Minimal Footer](/blocks/footer-minimal)
- [Stacked Footer](/blocks/footer-stacked)

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`, with no rounded classes. The registry bundles the components this block uses. Customize the links and content for your application.
