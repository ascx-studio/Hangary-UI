# Banner

A dismissible announcement banner with primary, secondary, ghost, and destructive variants.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/banner.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/banner.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/banner.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/banner.json",
}} />

## Usage

```tsx
import { Banner } from "@/components/hangry-ui/components/banner";

<Banner message="Your workspace is ready." />
```

## Variants

Set `variant` to `primary`, `secondary`, `ghost`, or `destructive`. The preview above shows all four.

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
