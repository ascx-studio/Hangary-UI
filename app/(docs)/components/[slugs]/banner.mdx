# Banner

A dismissible status banner with matching icons, optional descriptions, reduced-motion-aware reveal and hover animations, and neutral, info, success, warning, and error variants.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/banner.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/banner.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/banner.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/banner.json",
}} />

## Usage

```tsx
import { Banner } from "@/components/hangry-ui/components/banner";

<Banner
  variant="warning"
  message="Your trial expires in 3 days."
  description="Upgrade to keep access to all features."
/>
```

## Variants

Set `variant` to `neutral`, `info`, `success`, `warning`, or `error`. Each variant includes a matching icon. Add `description` for supporting text.
