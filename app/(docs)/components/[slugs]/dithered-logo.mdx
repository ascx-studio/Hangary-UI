A logo silhouette filled with flowing, two-color ordered dithering. Uses the existing Dither Background shader and a CSS image mask.

## Installation

<InstallationMenu name="dithered-logo" />

## How to use

```tsx
import { DitheredLogo } from "@/components/hangry-ui/components/dithered-logo";

<DitheredLogo
  src="/your-logo.svg"
  alt="Your brand"
  ratio={2}
  color={[0.02, 0.86, 0.5]}
  pixelSize={3}
  speed={0.4}
  className="max-w-md"
/>;
```
