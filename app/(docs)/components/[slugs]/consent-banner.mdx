A consent notice with accept and reject actions. The optional close button only dismisses the notice; your app decides whether to save a choice and when to show the banner again.

## Installation

<InstallationMenu name="consent-banner" />

## How to use

```tsx
import { ConsentBanner } from "@/components/hangry-ui/components/consent-banner";

<ConsentBanner
  className="fixed bottom-5 left-5 z-50"
  onAccept={() => saveAnalyticsChoice("accepted")}
  onReject={() => saveAnalyticsChoice("rejected")}
  onDismiss={() => setBannerOpen(false)}
/>;
```

Save and apply the choice in your own analytics integration. Hide the banner after a choice is made. Dismissal does not call `onAccept` or `onReject`.
