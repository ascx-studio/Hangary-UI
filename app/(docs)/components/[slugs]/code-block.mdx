# Code Block

A scrollable code block with an optional filename, line numbers, and an icon copy button. Syntax highlighting safely escapes markup and uses global theme colors.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/code-block.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/code-block.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/code-block.json",
}} />

## Usage

```tsx
import { CodeBlock } from "@/components/lazy-ui/components/code-block";

<CodeBlock
  code={'const greeting = "Hello, world!";\nconsole.log(greeting);'}
  language="javascript"
  filename="hello.js"
  showLineNumbers
/>
```

## Examples

Use `showLineNumbers` for numbered snippets and `filename` for a file label. Omit both for a plain snippet. The preview above shows a filename and numbered lines.

## Package managers

```tsx
<CodeBlock commands={{
  bun: "bun add highlight.js",
  npm: "npm install highlight.js",
  pnpm: "pnpm add highlight.js",
}} />
```

The Bun, npm, and pnpm buttons switch the displayed command. Copy copies the selected command without line numbers. Optional `packageManager` and `onPackageManagerChange` props allow you to control the selection.

## Setup notes

Use Tailwind CSS v4 and global `border`, `card`, `card-foreground`, `muted`, `muted-foreground`, and `ring` theme tokens. The registry installs highlight.js and lucide-react for highlighting and icons. No rounded classes are included. Copy requires a secure browser context, such as HTTPS or localhost; when copying fails, select the code and copy it manually. JavaScript/JSX, TypeScript/TSX, Bash, JSON, CSS, HTML/XML, and Python are highlighted using highlight.js. Unknown languages display as plain text.
