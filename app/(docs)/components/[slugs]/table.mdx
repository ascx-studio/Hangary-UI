# Table

A responsive table with composable headers, rows, cells, a caption, and an optional footer. Wide tables scroll horizontally.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/table.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/table.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/table.json",
}} />

## Usage

```tsx
import {
  Table, TableHeader, TableBody, TableRow,
  TableHead, TableCell, TableCaption,
} from "@/components/lazy-ui/components/table";

<Table>
  <TableCaption>Team members and their roles.</TableCaption>
  <TableHeader>
    <TableRow>
      <TableHead>Name</TableHead>
      <TableHead>Role</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>Alex Morgan</TableCell>
      <TableCell>Designer</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## Setup notes

Use the global theme tokens and Tailwind CSS v4. Borders use `border-border`, with no rounded classes. Use `TableHead scope="row"` for row headers, `TableCaption` to describe the table, and `TableFooter` for summary rows. Sorting and pagination can be composed separately.
