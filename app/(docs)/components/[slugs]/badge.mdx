# Badge

A compact badge with neutral, info, success, warning, error, blue, purple, pink, teal, and orange variants.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/badge.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/badge.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/badge.json",
}} />

## Usage

```tsx
import { Badge } from "@/components/lazy-ui/components/badge";

<Badge variant="success">Published</Badge>
```

## Variants

Use the `variant` prop to choose from: neutral, info, success, warning, error, blue, purple, pink, teal, orange. The preview above shows the available variants together.

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
