A reusable SVG logo component that animates the vector shapes supplied to it. It defaults to the portfolio logo, but animates custom SVG artwork passed as children.

## Installation

<InstallationMenu name="logo-animation" />

## How to use

```tsx
import { LogoAnimation } from "@/components/hangry-ui/components/logo-animation";

function MyBrandLogo() {
  return (
    <svg viewBox="0 0 24 24">
      <path d="M4 12 10 18 20 6" fill="none" stroke="currentColor" strokeWidth={2} />
    </svg>
  );
}

<LogoAnimation logo={<MyBrandLogo />} size={64} alt="My brand" />;
```

`logo` accepts an SVG component or inline SVG. Its SVG shapes draw in sequence and filled shapes fade in:

```tsx
<LogoAnimation logo={<MyBrandLogo />} alt="My brand" width={96} height={48} />
```

The default portfolio logo is used only when neither `logo` nor `children` is provided. The animation finds SVG paths, circles, ellipses, lines, polygons, polylines, and rectangles in the rendered logo, including shapes nested in groups. Raster logos fade in as a whole. `size` controls a square logo; set `width` and `height` for a custom aspect ratio. `className` styles the wrapper. The drawing animation respects the system reduced-motion preference.
