# Avatar Group

A stacked group of profile images with initials and an overflow count.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/avatar-group.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/avatar-group.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/avatar-group.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/avatar-group.json",
}} />

## Usage

```tsx
import { AvatarGroup } from "@/components/hangry-ui/components/avatar-group";

<AvatarGroup
  avatars={[
    { name: "Alex Morgan", src: "/alex.jpg" },
    { name: "Sam Rivera", src: "/sam.jpg" },
  ]}
  max={3}
  size={40}
/>
```
