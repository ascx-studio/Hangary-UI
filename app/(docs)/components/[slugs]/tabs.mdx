# Tabs

An accessible tabbed interface with default and line variants, disabled tabs, and keyboard navigation.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.rajeevpuri.com.np/r/tabs.json",
  npm: "npx shadcn@latest add https://ui.rajeevpuri.com.np/r/tabs.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.rajeevpuri.com.np/r/tabs.json",
}} />

## Usage

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from "@/components/lazy-ui/components/tabs";

<Tabs defaultValue="overview">
  <TabsList aria-label="Project sections">
    <TabsTrigger value="overview">Overview</TabsTrigger>
    <TabsTrigger value="settings">Settings</TabsTrigger>
  </TabsList>
  <TabsContent value="overview">Your project overview.</TabsContent>
  <TabsContent value="settings">Your project settings.</TabsContent>
</Tabs>
```

## Variants

Set `variant="default"` or `variant="line"` on `TabsList`. Give each `TabsTrigger` a unique `value` and use the same value on its `TabsContent`. Set `disabled` on a trigger to prevent selection. Set `orientation="vertical"` on `Tabs` for a vertical list.

## Keyboard navigation

Use Left and Right Arrow for horizontal tabs, or Up and Down Arrow for vertical tabs, to move between enabled tabs; Home for the first tab, and End for the last. Moving focus selects the tab automatically. Tab moves from the selected tab into its panel.

## Controlled selection

Pass `value` and update it through `onValueChange` to control the selected tab. Use `defaultValue` for an initial selection managed by the component. Panels stay mounted when hidden.

## Setup notes

Use Tailwind CSS v4 and the global theme tokens. Borders use `border-border`; no rounded classes or additional packages are required.
