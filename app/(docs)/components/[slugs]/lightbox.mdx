# Lightbox

Open a full-size image by clicking its thumbnail button, with keyboard and backdrop dismissal.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/lightbox.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/lightbox.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/lightbox.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/lightbox.json",
}} />

## Usage

```tsx
import { Lightbox } from "@/components/hangry-ui/components/lightbox";

<Lightbox
  src="/gallery/moth.jpg"
  alt="A monochrome moth against a dark background"
  caption="A closer look"
  triggerLabel="View moth"
/>
```

Press Escape or click outside the image to close it. The close button is keyboard accessible.
Background page scrolling is locked while the lightbox is open and restored when it closes.
Double-click the image to zoom in, then double-click again to reset. Keyboard users can press Enter or Space while the image is focused.
