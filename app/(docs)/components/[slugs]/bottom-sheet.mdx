# Bottom Sheet

A bottom-aligned modal sheet with native focus management and Escape dismissal.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/bottom-sheet.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/bottom-sheet.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/bottom-sheet.json",
}} />

## Usage

```tsx
import { BottomSheet } from "@/components/lazy-ui/components/bottom-sheet";

<BottomSheet title="Quick actions"><p>Choose your next step.</p></BottomSheet>
```

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
