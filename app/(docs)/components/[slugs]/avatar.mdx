  # Avatar

A profile image with initials and an image-error fallback.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/avatar.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/avatar.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/avatar.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/avatar.json",
}} />



## Usage

```tsx
import { Avatar } from "@/components/hangry-ui/components/avatar";

<Avatar name="Alex Morgan" src="/avatar.jpg" />
```

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
