# Breadcrumb

A breadcrumb navigation trail with links and a current-page indicator.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.rajeevpuri.com.np/r/breadcrumb.json",
  npm: "npx shadcn@latest add https://ui.rajeevpuri.com.np/r/breadcrumb.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.rajeevpuri.com.np/r/breadcrumb.json",
}} />

## Usage

```tsx
import { Breadcrumb } from "@/components/lazy-ui/components/breadcrumb";

<Breadcrumb items={[{ label: "Home", href: "/" }, { label: "Settings" }]} />
```

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
