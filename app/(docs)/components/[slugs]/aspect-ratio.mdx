A responsive container that preserves a chosen width-to-height ratio.

## Installation

<InstallationMenu name="aspect-ratio" />

## How to use

```tsx
import { AspectRatio } from "@/components/hangry-ui/components/aspect-ratio";

<AspectRatio ratio={9 / 16} className="overflow-hidden border border-border">
  {/* Image or other content */}
</AspectRatio>
```

`ratio` is the numeric width divided by height and defaults to `1`: use `16 / 9` for landscape, `9 / 16` for portrait, or `1` for a square. Standard div props, children, className, style, and ref are forwarded.
