# Blockquote

A styled quotation with optional author and source attribution.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/blockquote.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/blockquote.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/blockquote.json",
}} />

## Usage

```tsx
import { Blockquote } from "@/components/lazy-ui/components/blockquote";

<Blockquote quote="Make every detail count." author="Studio notes" />
```

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
