# Carousel

A manual carousel with previous and next controls and slide announcements.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/carousel.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/carousel.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/carousel.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/carousel.json",
}} />

## Usage

```tsx
import { Carousel } from "@/components/hangry-ui/components/carousel";

<Carousel slides={["First slide", "Second slide", "Third slide"]} />
```

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
