## How to use

```tsx
import { OutlineTrail } from "@/components/hangry-ui/components/outline-trail";

<OutlineTrail
  items={[
    { id: "overview", label: "Overview" },
    { id: "installation", label: "Installation" },
    { id: "usage", label: "Usage" },
  ]}
/>;
```

`items` uses the same shape as Outline. Entries without `href` track page headings; entries with `href` navigate between routes.
