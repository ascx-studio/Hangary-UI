# Card

A flexible content card with primary, secondary, ghost, and destructive variants, plus a body and footer.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.rajeevpuri.com.np/r/card.json",
  npm: "npx shadcn@latest add https://ui.rajeevpuri.com.np/r/card.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.rajeevpuri.com.np/r/card.json",
}} />

## Usage

```tsx
import { Card } from "@/components/lazy-ui/components/card";

<Card title="New project" description="Start with a blank canvas."><p>Your content here.</p></Card>
```

## Variants

Set `variant` to `primary`, `secondary`, `ghost`, or `destructive`. The preview above shows all four.

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
