# Card

A flexible content card with a title, description, body, and footer.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/card.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/card.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/card.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/card.json",
}} />

## Usage

```tsx
import { Card } from "@/components/hangry-ui/components/card";

<Card title="New project" description="Start with a blank canvas."><p>Your content here.</p></Card>
```

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
