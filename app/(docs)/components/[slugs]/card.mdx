# Card

A flexible content card with a title, description, body, and footer.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/card.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/card.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/card.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/card.json",
}} />

## Usage

```tsx
import { Button } from "@/components/hangry-ui/components/button";
import { Card, CardAction, CardContent, CardDescription, CardFooter, CardHeader, CardTitle } from "@/components/hangry-ui/components/card";

<Card>
  <CardHeader>
    <CardTitle>New project</CardTitle>
    <CardDescription>Start with a blank canvas.</CardDescription>
    <CardAction><Button variant="outline">Settings</Button></CardAction>
  </CardHeader>
  <CardContent>Your content here.</CardContent>
  <CardFooter><Button>Create project</Button></CardFooter>
</Card>
```

## Sizes and link cards

`size` accepts `"sm"` (16px gap and padding) or `"md"` (24px, the default). Variants use a TypeScript class map with no CVA dependency.

```tsx
<Card size="sm">
  <CardContent>A compact card.</CardContent>
</Card>

<Card as="a" href="/projects" size="md">
  <CardHeader>
    <CardTitle>Browse projects</CardTitle>
    <CardDescription>Open your workspace.</CardDescription>
  </CardHeader>
</Card>
```

Link cards change background on hover and show a keyboard focus outline. Avoid nesting buttons or other links inside a link card. Transitions respect reduced motion.

## Composition

Use `CardHeader` for the heading area, `CardTitle` and `CardDescription` for text, and `CardAction` for a control aligned to the top right. Place body content in `CardContent` and bottom actions in `CardFooter`.

Each component accepts `children`, `className`, and native attributes for its element: `article`, `header`, `h3`, `p`, `div` (action and content), or `footer`.

The legacy `title`, `description`, and `footer` props remain supported. Content is otherwise supplied through children; no default heading or description is inserted.

## Setup notes

Use Tailwind CSS v4. Cards use `ring-border`, a rounded border, and the shared color tokens. Customize `--focus-ring-width`, `--focus-ring-offset`, and `--duration-fast` as needed; defaults are 2px, 2px, and 150ms. No additional packages are required. Compose content with the exported parts and customize styling with `className`.
