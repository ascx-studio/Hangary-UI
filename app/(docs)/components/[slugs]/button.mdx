# Button

An accessible button with primary, secondary, ghost, destructive, and outline variants.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/button.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/button.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/button.json",
}} />

## Usage

```tsx
import { Button } from "@/components/lazy-ui/components/button";

<Button variant="outline">Continue</Button>
```

## Variants

Use the `variant` prop to choose from: primary, secondary, ghost, destructive, outline. The preview above shows the available variants together.

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
