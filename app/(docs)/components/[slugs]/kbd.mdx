# Kbd

A styled keyboard key or shortcut hint.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/kbd.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/kbd.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/kbd.json",
}} />

## Usage

```tsx
import { Kbd } from "@/components/lazy-ui/components/kbd";

<Kbd>Ctrl K</Kbd>
```

## Setup notes

Use Tailwind CSS v4. Borders use the global `border-border` token. No rounded classes or additional packages are required. Customize content with props and styling with `className`.
