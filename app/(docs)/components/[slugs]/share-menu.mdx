An icon button that opens a dropdown with Copy link, Other apps, X, ChatGPT, Claude, and Grok. Other apps opens the browser’s native share sheet when supported. NFC sharing appears on browsers that support Web NFC. Markdown and AI actions expect a working `llms.txt` endpoint for the page. NFC requires a compatible device and a writable tag.

## How to use

```tsx
import { ShareMenu } from "@/components/hangry-ui/components/share-menu";
import { Toaster } from "@/components/hangry-ui/components/toast";

<>
  <ShareMenu title="Share Menu — Hangry UI" url="https://ui.razeev.com/components/share-menu" />
  <Toaster />
</>;
```

Pass an absolute public URL so the social links and native share sheet can open it. Mount `Toaster` once near your app root.
