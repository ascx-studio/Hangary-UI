## How to use

```tsx
import { Toc } from "@/components/hangry-ui/components/toc";

<Toc
  items={[
    { id: "overview", label: "Overview" },
    { id: "installation", label: "Installation" },
    { id: "usage", label: "Usage" },
  ]}
/>;
```

Match each item ID to a heading on the page. Add `scroll-mt-24` to headings when using a fixed header. Add `className="sticky top-24"` to keep the card visible beside an article.

## Props

| Prop      | Type      | Default           | Description                                                  |
| --------- | --------- | ----------------- | ------------------------------------------------------------ |
| items     | TocItem[] | Required          | Unique heading IDs, labels, and optional level (1, 2, or 3). |
| title     | string    | Table of contents | Navigation label and heading.                                |
| className | string    | Empty             | Additional classes on the navigation.                        |
