## How to use

```tsx
import { Toc } from "@/components/hangry-ui/components/toc";

<Toc
  items={[
    { id: "overview", label: "Overview" },
    { id: "installation", label: "Installation" },
    { id: "usage", label: "Usage" },
  ]}
/>;
```

Match each item ID to an element on the page. The TOC highlights every listed target visible in the viewport. `level` controls indentation and marker width: level 1 is the longest, level 2 is shorter, and level 3 is shortest. The docs page also adds its title and preview to the TOC automatically.
