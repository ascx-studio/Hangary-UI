# SME Shader

A layered gradient and grid shader for product sections, previews, and hero panels.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/sme-background.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/sme-background.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/sme-background.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/sme-background.json",
}} />
