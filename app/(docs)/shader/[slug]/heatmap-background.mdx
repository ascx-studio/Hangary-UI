Flowing thermal colors move from deep blue through cyan and yellow to hot orange. Hover to add heat around the pointer. The temperatures are decorative and do not represent measured data.

Heatmap Background is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

## Installation

<InstallationMenu name="heatmap-background" />

## How to use

```tsx
import { HeatmapBackground } from "@/components/hangry-ui/shader/heatmap-background";

<HeatmapBackground
  colors={["#112069", "#1f3ca3", "#3265e7", "#6bd8ff", "#ffe77a", "#ff9a1f", "#ff4d00"]}
  scale={1.5} speed={0.2} intensity={0.9} className="grid place-items-center p-12"
>
  <h2 className="typography-section-title text-white">Turn up the heat.</h2>
</HeatmapBackground>;
```
