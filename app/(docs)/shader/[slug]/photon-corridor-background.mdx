Smooth monochrome dots form evenly spaced, aligned rows along perspective walls toward a dark vanishing point. Random individual lines light up with traveling highlights, bright cores, and soft bloom inspired by Light Ray. Move the pointer to gently steer the corridor.

Photon Corridor is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

## How to use

```tsx
import { PhotonCorridorBackground } from "@/components/hangry-ui/shader/photon-corridor-background";

<PhotonCorridorBackground speed={0.2} intensity={0.9}
  className="grid place-items-center p-12">
  <h2 className="typography-section-title text-white">Into the light.</h2>
</PhotonCorridorBackground>
```
