# LED Background

A luminous LED matrix with a sweeping highlight and a soft glow around the pointer. Designed for full-width sections with subdued lighting and room for readable content.

## Installation

<CodeBlock commands={{
  bun: "bunx shadcn@latest add https://ui.razeev.com/r/led-background.json",
  npm: "npx shadcn@latest add https://ui.razeev.com/r/led-background.json",
  pnpm: "pnpm dlx shadcn@latest add https://ui.razeev.com/r/led-background.json",
  yarn: "yarn dlx shadcn@latest add https://ui.razeev.com/r/led-background.json",
}} />

## Usage

```tsx
import { LedBackground } from "@/components/hangry-ui/shader/led-background";

<LedBackground speed={1} interactive className="grid place-items-center p-12">
  <h2 className="typography-section-title text-white">Light up your next idea.</h2>
</LedBackground>
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `speed` | `number` | `1` | Nonnegative animation speed multiplier. Set 0 to stop the automatic sweep. |
| `intensity` | `number` | `0.65` | Background brightness, clamped to 0–2. |
| `interactive` | `boolean` | `true` | Brighten LEDs around the pointer. |
| `children` | `ReactNode` | — | Content displayed above the shader. |
| Native div props | `ComponentProps` | — | Classes, styles, IDs, and accessibility attributes on the container. |

## Setup notes

The memoized wrapper uses a shared WebGPU renderer and shaders sized for background sections. The container has a minimum height of 24rem, customizable with className. The shader renders at the actual container dimensions with device pixel ratio 1. LED spacing stays at 16 CSS pixels; the light ray uses aspect-correct coordinates with a wider atmospheric glow. Neither effect stretches a wordmark-sized canvas.

Renders at 30fps. Reduced motion shows a still frame and disables pointer effects. Touch input skips hover behavior. With speed 0, interaction remains active; also set interactive to false to draw only once. A static CSS LED pattern remains visible without WebGPU. Decorative layers are hidden from assistive technology and do not intercept clicks. GPU resources and listeners are released on unmount.

Use Tailwind CSS v4 and the existing WGSL loader and TypeScript declaration from the [Dither Background setup notes](/shader/dither-background). Installation includes both background shader sources used by the shared renderer. No additional dependencies are introduced.
