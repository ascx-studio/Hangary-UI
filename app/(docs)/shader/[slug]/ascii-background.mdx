An animated field of bitmap ASCII characters reveals flowing patterns in emerald light. Hover to brighten the character field. Glyphs are rendered in the shader; no font or image is required.

ASCII Background is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

## Installation

<InstallationMenu name="ascii-background" />

## How to use

```tsx
import { AsciiBackground } from "@/components/hangry-ui/shader/ascii-background";

<AsciiBackground cellSize={14} speed={0.2} intensity={0.9} className="grid place-items-center p-12">
  <h2 className="typography-section-title text-white">A different perspective.</h2>
</AsciiBackground>;
```
