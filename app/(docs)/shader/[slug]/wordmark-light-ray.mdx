A continuous blue-white light ray sweeps across the wordmark with a bright core, soft glow, and fading trail. Hover the mark to pull the beam toward the pointer.

Wordmark Light Ray is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

<InstallationMenu name="wordmark-light-ray" />

## How to use

```tsx
import { WordmarkLightRay } from "@/components/hangry-ui/shader/wordmark-light-ray";

<WordmarkLightRay />
```

The component uses `/wordmark.svg` as its mask and requires browser WebGPU support. It cleans up the shader effect, surface, and GPU device when unmounted. Reduced-motion preferences stop the continuous scan while keeping the pointer response available.
