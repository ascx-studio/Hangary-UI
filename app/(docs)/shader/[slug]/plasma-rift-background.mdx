Cyan, white, and emerald ribbons fold into a dark vortex inspired by luminous plasma. Move the pointer to shift the vanishing point.

Plasma Rift is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

## How to use

```tsx
import { PlasmaRiftBackground } from "@/components/hangry-ui/shader/plasma-rift-background";

<PlasmaRiftBackground speed={0.2} intensity={0.9}
  className="grid place-items-center p-12">
  <h2 className="typography-section-title text-white">Through the rift.</h2>
</PlasmaRiftBackground>
```
