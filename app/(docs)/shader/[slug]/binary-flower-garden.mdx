Interactive physics-driven floral stems oscillating in a simulated wind field, featuring petal collision mechanics and shedding dynamics. Rendered directly through hardware-accelerated WebGPU WGSL fragment shaders with real-time binary glyph matrix sampling.

The breeze occasionally drops a random petal. Click any flower head to shed petals that flutter down to the ground. Each shed petal starts growing back automatically three seconds after it lands on the soil. Double-click to trigger a radial blooming animation and regrow missing petals. Drag flowers into each other to cause collisions and petal drops.

Inspired by [Sam Who’s post on X](https://x.com/samwhoo/status/2116317667921625158?a=f3RiaTTBcEl1adG_NJ4&s=20) and [Bloom filters](https://samwho.dev/bloom-filters).

## How to use

Import the component and optionally set the theme, wind speed, or custom classes. Set `windSpeed` from 0 (off) to 3× normal. Changing wind speed keeps growth and petal regrowth running at their normal pace.

```tsx
import { BinaryFlowerGarden } from "@/hangry/shader/binary-flower-garden";

export default function BloomDemo() {
  return (
    <div className="w-full max-w-5xl mx-auto p-4">
      <BinaryFlowerGarden windSpeed={1} className="h-[32rem] w-full" />
    </div>
  );
}
```
