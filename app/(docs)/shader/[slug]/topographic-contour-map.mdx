Animated elevation contours on a near-black canvas, with height-based colors, stronger major lines, and small elevation labels. Hover to raise the terrain; press to create a depression. The left side fades into the background to leave room for content.

Topographic Contour Map is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

## How to use

```tsx
import { TopographicContourMap } from "@/components/hangry-ui/shader/topographic-contour-map";

<TopographicContourMap
  colorScheme="amber"
  showLabels
  mouseInfluence
  scale={3}
  density={24}
  lineWidth={1}
  speed={0.08}
  className="grid place-items-center p-12"
>
  <h2 className="typography-section-title text-white">Find your own path.</h2>
</TopographicContourMap>;
```

The terrain is generated for decoration; it does not represent a real geographic location. The noise
field evolves smoothly over time. Every fourth contour is emphasized. Labels follow their elevation
contours and use a built-in bitmap font without additional font dependencies.
