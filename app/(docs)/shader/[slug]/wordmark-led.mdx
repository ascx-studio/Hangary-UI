A field of individually pulsing WebGPU LEDs fills the complete wordmark instead of the source example's triangular light area.

Wordmark LED is a vgpu-powered React UI component that renders a WGSL shader through WebGPU. It supports reduced motion and provides a fallback for browsers without WebGPU.

The source image supplies the colors. Pass `src` to use your own logo and `alt` for its accessible label.
